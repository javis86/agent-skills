# Agent Skills

This repository contains a collection of custom skills that extend the capabilities of the Gemini CLI agent.

## Available Skills

### Anki Card Creator
Extracts vocabulary from text and formats it into Tab-Separated Values (TSV) for Anki, creating both basic and cloze deletion cards. Use when asked to create Anki cards from notes.

### IOL Performance Analyzer
Calculates and analyzes Month-To-Date (MTD) or period-over-period financial performance, earnings, stock splits, and loss/gain causes of an InvertirOnline (IOL) portfolio. Use when asked to analyze IOL portfolio performance or adjust for corporate actions.

### Mermaid to PNG
Converts Mermaid diagrams into PNG images using a Python script. Use this skill when you need to generate a visual representation (PNG) of a Mermaid diagram description (e.g. flowcharts, sequence diagrams).

### Vocabulary Definer
Finds definitions and pronunciations for a list of vocabulary words in a markdown file and updates the file with the formatted results. Use when asked to define a list of words.
