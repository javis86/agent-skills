# Vocabulary Output Format

When presenting the vocabulary list, use the following markdown format for each word:

- **word** /pronunciation/ (phonetic spelling): definition.

## Example

- **avoid** /əˈvɔɪd/ (uh-VOID): to keep away from; to prevent; to refrain from.
- **novelty** /ˈnɑːvlti/ (NAHV-uhl-tee - US), /ˈnɒvlti/ (NOV-uhl-tee - UK): the quality of being new, original, or unusual.
